# Epic Terrain Compatible (Unofficial Port)

Found a bug or have a suggestion for the Minecraft 26.1–26.3 port? [Search existing issues](https://github.com/GuoWQ222/epic-terrain-compatible-port-feedback/issues) or [open a new issue](https://github.com/GuoWQ222/epic-terrain-compatible-port-feedback/issues/new). English and Chinese are both welcome.

For a bug report, include your Minecraft version, loader and loader version (Fabric, Forge, or NeoForge), and the port JAR filename. Describe the steps to reproduce the problem, what you expected, and what happened. For terrain issues, include the world seed, coordinates, and terrain settings if available. For a crash, attach the relevant log excerpt. For a suggestion, describe what you’d like to change and why.

## 中文反馈

如果你在 Minecraft 26.1–26.3 的非官方移植版中遇到问题，或想提改进建议，欢迎用中文留言。可以先[查看已有反馈](https://github.com/GuoWQ222/epic-terrain-compatible-port-feedback/issues)，也可以直接[提交新反馈](https://github.com/GuoWQ222/epic-terrain-compatible-port-feedback/issues/new)。

报告故障时，请写明 Minecraft 版本、加载器名称和版本、移植版 JAR 文件名，以及怎样重现问题、你预期看到什么、实际发生了什么。地形异常可以附上世界种子、坐标和地形设置，崩溃可以附上相关日志片段。如果是建议，写下希望改进的地方和使用场景即可。
